# LDSpaceGame v0.1.0-prototype 发布说明

- 版本号：`v0.1.0-prototype`
- 标签名：`v0.1.0-prototype`

- 构建时间：`2026-05-22 10:09:22 +08:00`
- 构建平台：`Microsoft Windows 10.0.26200`
- 发布类型：静态 HTML5 原型归档

## 运行方式

直接双击或用浏览器打开本目录下的 `index.html` 即可运行。

目录结构需要保持如下相对路径：

```text
index.html
src/main.js
src/styles.css
```

## 主要变更

- 提供 v0.1 静态 HTML5 可玩原型，可在浏览器中直接运行。
- 支持空间站核心、框架扩展、采矿站、炮塔、电力分配和敌袭波次。
- 支持点击移动、邻格建造、设施菜单确认、胜负结算和重开。
- 保留阶段 A 目标反馈：建造足够结构并接近目标点后显示能力达成。

## 已知问题

- 当前为单文件 Canvas 原型，未包含资源加载、设置菜单、存档或音频。
- 操作提示和交互反馈仍偏调试向，缺少正式 UI 包装。
- 平衡参数和敌袭节奏仅用于快速验证玩法闭环，尚未做长期体验调优。
- 未做多浏览器兼容矩阵验证，本次仅完成文件级归档自检。

## 后续优化方向

- 补齐正式 HUD、建造提示、命中反馈、受击反馈和胜负流程包装。
- 增加资源采集、设施升级、敌人类型和更明确的阶段目标。
- 梳理静态发布流程，后续可加入自动化校验和可复现构建记录。
- 在正式发布前补充浏览器兼容性与基础玩法冒烟测试。
