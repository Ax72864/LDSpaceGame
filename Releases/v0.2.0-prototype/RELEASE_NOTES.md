## 主要变更

- 推进器现在可建造，并会在供电在线时提高空间站移动速度。
- 敌袭节奏调整为建造第 2 个设施后进入预警，第 4 个设施触发敌人波次。
- 修复重开按钮重复绘制的问题，失败或胜利后结算界面更清晰。
- 调整早期采矿率和敌人速度，让开局更容易形成采矿、建造、防御的短循环。
- 建立 L0、L0.5、L2、L2.5 分层验证体系，覆盖静态检查、浏览器冒烟和关键玩法路径。

## 已知问题

- 当前仍为 Canvas 静态原型，未包含资源加载、设置菜单、存档、音频或正式发布壳。
- UI 和操作反馈仍偏调试向，建造菜单、战斗反馈和胜负结算包装需要继续打磨。
- 敌人类型、资源点、设施成长和长期经济循环仍较简化，参数仅适合原型阶段验证。
- 仍未做多浏览器兼容矩阵验证，目前主要以 Edge headless 和静态文件归档检查为准。

## 后续优化方向

- 强化推进器、采矿、炮塔之间的取舍，让移动、防御和资源扩张形成更清晰的策略节奏。
- 补齐正式 HUD、建造确认、命中反馈、受击反馈、敌袭预警和胜负流程表现。
- 增加更多敌人行为、资源分布和阶段目标，让一次游玩有更明确的目标压力。
- 将静态归档检查纳入自动化发布脚本，减少手工复制和说明书漏项风险。
