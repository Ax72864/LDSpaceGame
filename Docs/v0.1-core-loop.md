# LDSpaceGame v0.1 最小核心循环设计

## 1. 系统策划判断

v0.1 目标是验证最小可玩闭环：点击移动空间站 → 获取/消耗资源 → 扩展框架与设施 → 面对简单威胁 → 达成胜败条件。

阶段 A 只验证「空间站核心、框架扩展、金属/电力、点击移动」的工程框架；阶段 B 在此基础上加入采矿、炮塔、一波敌人，形成完整 3–5 分钟单局。

## 2. 3–5 分钟单局流程

### 阶段 B（完整版）

1. **开局 0:00** — 核心 + 金属 40 + 电力由核心产出；地图生成小行星、敌人出生点、胜利目标点。
2. **建造 0:00–1:00** — 扩展框架，在框架上建采矿站或炮塔。
3. **采矿移动 1:00–2:30** — 点击移动至小行星，采矿站产出金属；电力不足则停工。
4. **敌袭 2:30–4:00** — 一波敌人接近核心；炮塔自动射击；玩家调整站位。
5. **结算** — 胜利：敌人全灭且核心存活；失败：核心耐久 ≤ 0。

### 阶段 A（当前工程子集）

1. 核心生成。
2. 点击地图移动。
3. 点击核心相邻格建造框架（消耗金属）。
4. 核心提供电力占位。
5. HUD 显示金属、电力、模块数。
6. **临时胜利**：建造 ≥5 个框架并移动到目标点。

## 3. 模块列表

| 阶段 | 模块 |
|------|------|
| A | 启动、核心、框架建造、金属/电力、点击移动、基础 UI、阶段 A 目标 |
| B | 小行星、采矿站、炮塔、敌人一波、战斗、胜败结算 |

## 4. 资源规则

### 金属

| 项目 | 阶段 A | 阶段 B |
|------|--------|--------|
| 初始 | 100（原型暂用 50） | 40 |
| 来源 | 仅初始 | 采矿站 5/秒（半径 160px） |
| 框架 | 10（原型 5） | 10 |
| 采矿站 | — | 25 |
| 炮塔 | — | 30 |

### 电力

- 核心产出 10；采矿站需求 4；炮塔需求 3。
- 产出 < 需求时按优先级供电：炮塔 > 采矿站。
- 电力不足则对应设施停工。

## 5. 胜败条件

| 阶段 | 胜利 | 失败 |
|------|------|------|
| A | ≥5 框架 + 到达目标点半径 | 无（可重开） |
| B | 敌人全灭 + 核心存活 | 核心耐久 ≤ 0 |

建议战斗数值：核心 100 HP；敌人 5 只×20 HP；敌人 5 DPS；炮塔 10 伤害/0.8s；射程 220px。

## 6. 玩家操作

| 操作 | 输入 | 结果 |
|------|------|------|
| 移动 | 点击空地 | 设移动目标 |
| 建框架 | 点击高亮邻格 | 扣金属 |
| 建设施 | 点击框架选类型 | 阶段 B |
| 重开 | 按钮 | 重置关卡 |

## 8. 验收标准

**阶段 A**：能扩展框架、扣金属、点击移动、HUD 可读、可完成临时胜利目标。

**阶段 B**：采矿、炮塔、敌袭、自动战斗、胜败结算。

**v0.1 不做**：推进器物理、旋转、遮挡、脱落、科技、局外、多关卡、联机。
